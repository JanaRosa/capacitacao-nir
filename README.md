# Trilha de Capacitação do Núcleo Interno de Regulação (NIR)

## 📚 Capacitação NIR

Projeto desenvolvido para organização e disponibilização de conteúdos de capacitação voltados às atividades do Núcleo Interno de Regulação (NIR).

A proposta é reunir treinamentos, vídeos e materiais de apoio em um único espaço, facilitando o acesso e contribuindo para a padronização dos processos e das práticas do setor.

---

## 🎯 Objetivo do projeto

Construir uma trilha de capacitação do NIR, reunindo conhecimentos, treinamentos e materiais que contribuam para a melhoria dos processos, da comunicação e da organização do trabalho.

O projeto poderá futuramente incorporar POPs, fluxos, protocolos, indicadores e outros materiais relacionados às atividades do NIR.
